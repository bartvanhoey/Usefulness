
## Chrome

## Useful Keyboard Shortcuts

| Shortcut | Action |
| -------- | ------ |
| `F12` | Open/Close Chrome DevTools |
| `CTRL+SHIFT+C` | Open Console in Chrome DevTools |
| `CTRL+F` | Search in page |
